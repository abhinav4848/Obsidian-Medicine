# Instructions for Codex work in this vault

- Read [Obsidian note preferences](<Obsidian note preferences.md>) before creating or editing study notes.
- Keep Codex-specific instructions, preferences and other administrative files in this `Codex` folder, including when study notes are explicitly authorized elsewhere. Do not create administrative files in the vault root or study-note folders.
- Only create or edit files inside the vault's `Codex` folder unless the user explicitly authorizes a particular action elsewhere.
- Reading other vault files is permitted. Never edit original notes, vault settings, or existing attachments without that authorization.
- Store all new attachments in `Codex/attachments/`.
- For medical reviews, distinguish factual errors, outdated guidance, and oversimplification. Verify consequential claims against UK primary guidance and include original-note links, locations, and sources.
