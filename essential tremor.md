Essential tremor (previously called benign essential tremor) is an [[autosomal inheritance|autosomal dominant]] condition which usually affects both upper limbs. 
Postural i.e. during action. But absent during rest. 
# Features 
- b/l postural tremor of 4-12 Hz (commonly 6-8 Hz): worse if arms outstretched
- improved by alcohol and rest
- most common cause of titubation (head tremor)
# Management  
- ==Propranolol== is first-line
- primidone (barbiturate anticonvulsant) - useful alternative or adjunct if propranolol contraindicated or inadequate. Max dose is 750mg/day. Patients start with 25mg BD for first week then 50mg BD for next 1-2 months. It's started by specialists usually after Gabapentin 300mg TDS is reached. Eventually if tolerating primidone well, gabapentin can be reduced. 
# DDx
While [[parkinson's disease|Parkinsonian]] tremor can appear similar, it is typically a 4-6 Hz rest tremor that improves with action, unlike this patient's postural tremor.
