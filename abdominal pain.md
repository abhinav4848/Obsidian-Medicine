# Alarm symptoms 🚩
| Alarm feature                                                    | What it may suggest                                  |
| ---------------------------------------------------------------- | ---------------------------------------------------- |
| **Severe or rapidly worsening pain**                             | Acute abdomen, perforation, ischaemia, obstruction   |
| **Peritonism** — guarding, rigidity, rebound tenderness          | Peritonitis / perforation                            |
| **Haemodynamic instability** — hypotension, tachycardia, syncope | Haemorrhage, sepsis, ruptured AAA, etc.              |
| **GI bleeding** — haematemesis, melaena, significant PR bleeding | GI haemorrhage                                       |
| **Persistent vomiting / inability to keep fluids down**          | Obstruction, severe infection, metabolic pathology   |
| **Abdominal distension + inability to pass stool/flatus**        | Bowel obstruction                                    |
| **Fever / rigors / systemic toxicity**                           | Intra-abdominal infection or sepsis                  |
| **Jaundice**                                                     | Biliary obstruction, hepatitis, pancreatic pathology |
| **Unintentional weight loss / anorexia**                         | Malignancy, chronic inflammatory disease             |
| **Palpable abdominal mass**                                      | Malignancy, aneurysm, organomegaly                   |
| **Change in bowel habit**, particularly new/persistent           | [[cancer- colorectal\|Colorectal cancer]], IBD       |
| **Iron-deficiency anaemia**                                      | GI malignancy or chronic GI blood loss               |
| **Dysphagia or persistent upper-GI symptoms**                    | Upper GI malignancy/structural disease               |
| **New symptoms in older age**                                    | Higher risk of malignancy and serious pathology      |
| **Pregnancy / possible pregnancy**                               | Ectopic pregnancy, miscarriage, etc.                 |
| **Urinary retention / haematuria**                               | Urinary obstruction, stones, malignancy              |
| **Pain radiating to back + collapse/shock**                      | AAA, pancreatitis, etc.                              |
